# 図の伝達・統計・可読性に関する共通基準

AGENTS、作図SKILL、そのchecklistに、図の目的を一文で決めること、初見読者に必要な用語を説明すること、結論を支える統計の十分さ、最終掲載/投影サイズでの可読性、詰め込みを減らすことを追加。小さい文字が苦手な読者や会場後方での理解を目標とし、スマートフォン表示を要件にしない。埋込/重なりの機械検査だけで資料完成としない。

Python semantic helperは観測値・比較データを、誤差の有無にかかわらず接続線なしの点で描く。誤差棒も保持する。モデルは曲線のまま。ratioと残差、ROOTのTGraphErrors例も点のみへ変更し、凡例のdata記号から線を除去。点のサイズを大きくし、標準見本の題名、比の軸ラベル、2Dの任意単位と差分の比較対象を説明。配色・数値計算・CSV・採用config・基本寸法/文字サイズpresetは変更なし。データCSVのSHA256検査を通過。

既存環境でPython/ROOTの初期例、配色比較、標準paper/slides例を再生成。publication_checksは実Matplotlib artistを確認し、誤差付きdata/誤差なしdataのlinestyle=None、model曲線保持、未知condition拒否、配色、data hash、PDFfontを検査してPASS。ROOT埋込6PDFとcolor_checksのfont/LUT/外部fontなし描画もPASS。公式skill validator PASS。

標準4ページ、配色比較4ページ、初期比較12ページをPDFから実描画し、点がつながっていないこと、モデル/基準線の区別、peakとlegend、文字の重なり/切れを目視確認。標準4ページは外部font空設定とのpixel差0。初期9panel一覧は比較用で発表資料の完成見本として合格扱いにしない。合成例の低統計binは描画例であり、そこから科学的結論を主張しない。

実会場の投影、印刷機、小さい文字が苦手な実読者による評価は未実施。実研究図では科学的主張に必要な精度と事象数/有効統計/誤差/相関を再評価し、足りなければ結論保留・探索表示・議論から除外する。単純なbin数thresholdは設けない。consumerのsubmoduleは従来の固定SHAのままで一括更新していない。
